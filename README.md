# 📊 E-Commerce Sales Dashboard (Excel)

An interactive Excel dashboard analyzing e-commerce sales performance, customer buying behavior, and delivery metrics — built using Pivot Tables and dynamically connected Slicers.

## 🎯 Overview
This dashboard turns raw order-level e-commerce data into a clean, business-ready view for tracking performance and spotting trends at a glance.

## 🎥 Walkthrough

## 📊 KPIs Tracked
- Total Orders
- Total Quantity
- Total Amount
- Average Customer Rating
- Average Days to Deliver

## ❓ Business Questions Answered
- Sales trend over the last 13 weeks
- How customers prefer to buy (App, Instagram, Partner App, Website)
- How many units customers typically purchase per order
- Which products are most popular
- Gender split of the customer base
- Where customers are located
- Average delivery time
- Monthly customer satisfaction trend

## 🛠 Tools & Skills Used
- Microsoft Excel — Pivot Tables & Pivot Charts
- Interactive Slicers connected across multiple visuals
- KPI card design and dashboard layout
- Data visualization and reporting best practices
